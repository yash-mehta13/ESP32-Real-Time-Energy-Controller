# Hardware validation records

No validation records have been committed yet. Add one file per bench session
(for example `2026-01-15-pzem-bench.md`) following the checklist in
[../test-procedure.md](../test-procedure.md) section 7: firmware commit,
environment and toolchain, parts and verified relay polarity, reference
instrument and calibration status, raw readings, observed protection
behaviour and an independent confirmation that the load was de-energised.

Do not add numbers that were not measured, and do not include credentials.
